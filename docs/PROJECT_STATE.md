## 已冻结

- NAS 独立运行，电脑不参与日常流程。
- 单镜像、单容器、Python/Node 两个独立受监督进程。
- 下载器独占小米云认证；识别服务只读本地录像与脱敏状态日志。
- SCRFD 2.5G + ArcFace R50 + ONNX Runtime CPU，单录像推理并发。
- 不预录人脸；自然学习永久持续。
- 多人同框逐人跟踪，同帧人物永久不可合并。
- 高质量、多样代表样本永久保存且总数不封顶。
- 身份与风险通知训练期关闭，运行故障通知开启。
- 普通本地制品保留 35 天；115 真实备份和删除归专项任务。
- 管理页面密码直登、12 小时可撤销服务端会话。
- 识别结果不得控制门锁。

## 工作值

- Web 回环端口：`18125`。
- ONNX Runtime：intra-op `2`，inter-op `1`。
- 抽帧：`2 FPS`，每段最多 `120` 帧。
- 分析失败重试：`5/20/60` 分钟。
- 登录：15 分钟窗口内 5 次失败后锁定 30 分钟。
- 人物检索：历史原型不删除，最多启用 32 个多样检索原型及综合质心。

这些值是针对 N100 和当前短录像量的初始工作值，需以 NAS 私有性能证据复核；不能当成最终准确率阈值。
