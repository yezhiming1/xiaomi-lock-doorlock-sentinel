# 项目变更记录

## V0.0.5（候选）

- 接口时间统一输出为明确 UTC，管理页面固定按北京时间显示，不再受访问设备时区影响。
- “今天/昨天”改为按北京时间自然日边界判断，并新增跨日回归测试。
- 浏览器标题、登录页和品牌区显示“门锁观察簿 V0.0.5”，事件与运行时间明确标注北京时间。
- 本地静态检查、Python/Node 测试、迁移往返、合成烟雾链、模型锁和公开目录审计通过；
  目标 NAS、Edge 与公网验收尚未执行，保持 `UNKNOWN`。

## V0.0.3（已发布并部署）

- “运行”页面的人工操作与对象名称改为可读中文，不再直接显示内部英文操作名或完整对象标识。
- 待确认人物可以直接并入已确认人物；合并选择器优先展示并默认选择已确认人物。
- 新增直接并入、幂等重放、撤销恢复与同框不可合并测试，保持多人同框的永久约束。
- 完成 Edge 桌面/手机交互、NAS 隔离侧车、无损升级、受控重启、公网密码登录和共享网关回归验收。

## V0.0.2（已发布并部署）

- 人物名称允许留空，并按关系自动生成连续、可读且不复用历史编号的默认名称。
- 待确认人物簇提供大图、样本切换与对应录像播放，帮助在命名前核对身份。
- 视频继续通过登录保护的同源媒体接口按需读取，不暴露真实路径或新增公开媒体地址。
- 完成 Edge 桌面/手机交互、NAS 无损升级、受控重启、公网密码登录和共享网关回归验收。

## V0.0.1（已发布并部署）

- 将旧参考方案重构为 NAS 原生 SCRFD/ArcFace 自然学习系统。
- 增加管理页面、安全登录、多人纠错、运行审计和下载失败桥接。
- 将 115 上传与删除职责移交备份专项任务，本项目只提供清单与回执。
- 将真实域名、私有路径、模型、录像、人脸和凭据从公开树隔离。
- 建立版本备份、镜像归档、公开树审计和分层验收记录。
- 完成冷白证据账簿管理端、响应式底部导航、AA 对比度和 44px 触控目标验收。
- 修复 Windows 短路径别名导致的安全目录误判，同时继续拒绝符号链接和目录联接。
- 增加 NAS `root:root 0640` 输入兼容，保持宿主权限不变且容器输入只读。
- 完成 NAS 生产部署、当前私有录像批次处理、数据库完整性、资源上限和源输入不变验收。
- 完成公网密码登录、安全 Cookie、服务端会话、CSRF 退出与共享入口既有路由回归。
- 增加公开 GitHub CI；统一执行 Ruff、Python/Node 测试、迁移往返、合成烟雾、模型锁、
  公开树审计和 Compose 配置验证。

代码级详细变更见 `doorlock-sentinel/CHANGELOG.md`。
