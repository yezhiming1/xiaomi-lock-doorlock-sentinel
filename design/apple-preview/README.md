# Apple Design 交互候选

2026-10-06：按用户要求，以 Apple Design 主导重新设计，ui-ux-pro-max 只核查可读性与交互，不生成竞争设计系统。当前仅为本地方案，不是新版本或部署。

## 视觉与交互契约

- 面向家庭管理员，原生 HTML/CSS/JavaScript，无框架、外部字体、依赖或外部资源。
- 系统字体、灰白背景、白色内容面、蓝色选择与操作、16px 正文、紧凑标题；不用营销大标题、渐变、指标卡墙或装饰玻璃。
- 轻磨砂只用于导航层；正文实色。减少透明度或高对比度偏好时转为实色。
- 事件列表与详情保持空间关系；移动端用原生对话框呈现详情，关闭后焦点回到来源。不引入拖动、弹簧库或手势，原生滚动保留浏览器惯性。
- 控件按压即时响应；短色彩/透明度反馈，不锁定导航。减少动态时无位移动画。
- 已确认人物每类别一个入口，展开查看所有人物；待确认独立入口，不替未知人物推断分类。外卖排序在快递之前。
- 运行页用中文状态与错误；设置保留训练期通知、安全会话等产品语义，所有操作明确为模拟。
- 登录预览不接收任何密码，仅用按钮模拟进入；真实单密码认证、CSRF、限速和会话由现有服务保留，未在原型内复制。

## 页面与边界

五个路由：`#login`、`#events`、`#people`、`#operations`、`#settings`。
预览默认事件页，可切换登录页；记录、次数、人物均为合成示例，无真实照片或录像。
不使用 fetch、存储、Cookie、真实 API、媒体或云认证。确认与设置只修改当前页面内存，刷新恢复。
正式落地必须保留原有命名/改名/合并/拆分/误检/撤销/重试/媒体播放能力；原型只演示主要信息架构，不宣称实现全部业务操作。

## 检查与交付

ui-ux-pro-max 检查点：正文与辅助文字对比度、44px 控件、可见焦点、语义标题/导航/表格、对话框退出与焦点恢复、加载/空/错误反馈、小屏与字体放大。
预览不调用真实服务；只启动绑定回环的临时静态服务，查看结束后停止。
浏览器未验证的尺寸、屏幕阅读器或实机行为必须标记 UNKNOWN，不能用源码检查替代。

### 当前证据

- Node 语法与候选聚焦测试、公开树审计、差异空白检查已执行；截图位于 Git 忽略的 `design/screenshots/apple-preview/`，不放入公开树。
- Edge 1440、768、390 CSS px 初步布局无页面横向溢出；390 下可见按钮高度没有小于 44px 的项。
- 分类展开、原生弹窗 Escape 关闭与来源焦点恢复、移动事件详情、模拟开关、模拟登录、加载/空/错误与恢复入口已验证。
- 移动验收发现导航受父层 backdrop-filter 的固定定位包含块影响；关闭移动父层滤镜后复测，导航 bottom=844 与 844px 视口一致。保留初次截图作为失败证据。
- 屏幕阅读器、系统最大文字缩放、减少动态/透明度的实机行为和生产消费者未验证，保持 UNKNOWN。代码中的媒体规则不替代实际验收。
- 本轮不发布、不部署、不接真实业务；正式能力仍由现有生产界面提供。
