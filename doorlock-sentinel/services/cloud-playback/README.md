# 独立播放解析服务

门锁服务只读取已经核验的备份回执，以浏览器 User-Agent 向独立 Unix Socket 请求短期播放地址。
原录像接口返回 302，视频字节由 115 CDN 直接传给浏览器；即使本地文件存在，也不回退本地。
图片继续采用现有认证文件接口。没有有效备份回执时返回 409，解析服务故障时返回 503。

`resolver.py` 使用 Python 3.11+ 标准库，独立于识别进程运行。独立授权状态文件必须为服务
专有的 0600 文件，目录 0700；只将 Socket 目录挂入识别容器，不能挂入令牌目录。
Socket 目录为 root:10001、0750，Socket 为 10001:10001、0660。配置必须明确指定唯一项目
备份根目录，禁止使用网盘根目录。解析器不提供上传、删除、移动、公开分享或媒体代理接口。

启动参数：`python3 resolver.py --socket SOCKET --state STATE --project-root REMOTE_PROJECT_ROOT`。
STATE 格式为 `access_token`、`refresh_token`、`expires_at`（Unix 秒）；通过可见授权页面取得，
不能从其他 NAS 应用抽取。该文件和任何真实路径、签名地址不得进入仓库或日志。

服务只开放 Unix Socket；由 systemd 限制文件写入到独立授权状态和 Socket 目录，配合
`NoNewPrivileges`、`ProtectSystem=strict`、`ProtectHome`、内存/进程资源限制及专用启动单元。
挂载 Socket 的容器不能读取授权目录。首次启用前必须验证前代完整恢复集和现有服务健康。

115 元数据接口单进程串行，调用间隔至少 550ms；同路径、大小和浏览器 UA 的地址缓存 45 秒。
授权临近过期时串行刷新并原子保存、fsync、回读。刷新开始前落盘意图；结果不明确时保留
意图并停止自动重试，人工对账后再恢复，不能靠重启循环消费刷新令牌。HTTP 403/429 暂停
调用 300 秒，其他业务拒绝暂停 60 秒；不自动遍历目录或下载视频。

验证包含：认证前拒绝、回执与制品摘要/大小一致、本地存在与缺失均跳转、服务失效不回退、
路径越界与非法 CDN 拒绝、浏览器真实播放/拖动、令牌隔离，以及识别/通知双进程和原数据库保持。
回滚只切回已核验前代镜像和配置，保留当前业务数据库；待无消费者后再停新解析服务。
