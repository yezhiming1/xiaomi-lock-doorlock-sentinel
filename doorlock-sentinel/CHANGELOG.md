# 变更记录

## V0.0.1

- 建立 NAS 单镜像、单容器、Python/Node 双进程架构。
- 实现只读录像摄取、稳定性检查、SHA-256 去重、租约恢复和 `5/20/60` 分钟重试。
- 接入固定 SHA-256 的 SCRFD 2.5G、ArcFace R50 与 ONNX Runtime CPU。
- 实现多人物轨迹、完整同帧共现证据、永久不可合并约束和未知人物自然聚类。
- 实现不预录人脸的人工命名、改名、人物/簇合并、簇拆分、误检和撤销。
- 永久保留高质量多样代表样本，使用有界检索索引控制 N100 匹配成本。
- 建立 SQLite 单写者、Alembic 迁移、持久化 Outbox、审计和可撤销服务端会话。
- 新增密码管理页面，覆盖事件、证据、人物、失败重试、下载状态、备份回执、存储和审计。
- 新增企业微信官方智能机器人 WebSocket 适配层；训练期身份/风险通知默认关闭。
- 新增 `xiaomi-lock-cloud-video V0.0.4` JSONL 下载状态桥接，不复用任何云端认证。
- 新增制品清单、SQLite 在线快照与 115 专项任务校验回执契约。
- 加固 Trusted Host、Argon2id、持久限速、CSRF、安全响应头、路径边界、只读根文件系统和日志脱敏。
- 固定 Python/Node/基础镜像依赖，补充公开树扫描、自动验证、部署与回滚文档。
- 增加冷白证据账簿管理端的响应式、键盘、减少动态、44px 触控与 AA 对比度保障。
- 兼容 Windows 短路径与规范路径指向同一批准目录的场景，同时拒绝符号链接和目录联接。
- 兼容 NAS 下载器生成的 `root:root 0640` 源录像：专用 UID 10001 只增加容器内读取组，宿主权限和只读挂载不变。
- 修复最小 capability 模式下持久数据目录首次交权后无法幂等重启的问题，不增加 `DAC_OVERRIDE`。
- 为容器内 Supervisor 增加仅用于优雅结束 UID 10001 子进程的 `KILL` capability，并要求重启日志无权限错误。
