# 变更记录

## V0.0.6

- 在现有“与您家的关系”中加入“我”和“朋友”，确认人物与修改人物时均可选择。
- 人物卡片、事件详情和合并选择器使用对应中文标签；历史人物保持原分类，不自动改写。
- 名称留空时继续使用既有按类别编号规则，可生成“我 1”“朋友 1”等名称。
- “我”沿用家人的风险减分；“朋友”保持已知人物的中性风险语义，不自动忽略异常行为。
- 固定 Python、Web、Compose、镜像标签和企业微信适配层版本为 `0.0.6`。

## V0.0.5

- 管理页面的事件、下载、失败和人工操作时间固定按 `Asia/Shanghai` 显示，不再跟随浏览器
  或设备的本地时区。
- API 将 SQLite 返回的无时区时间按既有 UTC 存储约定规范化，并统一输出带 `Z` 的 UTC
  时间戳，避免浏览器把时间误当成本地时间。
- “今天/昨天”按北京时间的自然日边界计算，并增加跨 UTC 16:00 边界的回归测试。
- 浏览器标题、登录页和左侧品牌名称统一显示“门锁观察簿 V0.0.5”；事件页和运行表格
  明确标注“北京时间”。
- 固定 Python、Web、Compose、镜像标签和企业微信适配层版本为 `0.0.5`。

## V0.0.4

- 兼容下载器 V0.0.8 的北京时间录像名 `xiaomi_lock_YYYYMMDDTHHMMSS.mp4` 及同秒
  `-02`、`-03` 序号，同时继续读取旧 UTC+毫秒+摘要格式。
- 新人脸裁剪图命名为 `<录像名>-aNNN.jpg`，带人脸框场景图命名为
  `<录像名>-bNNN.jpg`；轨迹序号从 `001` 开始。
- 新增 `doorlockctl migrate-media-names` dry-run 和 `--apply`；要求下载器已先改名，
  校验录像/图片大小与 SHA-256、拒绝任何回执、使用无覆盖硬链接切换图片，并在一个
  SQLite 事务中更新摄取、事件源制品与派生制品路径。
- 迁移命令使用独占锁，重复运行可安全返回零待迁移；不调用或修改 115。
- 固定 Python、Web、Compose、镜像标签和企业微信适配层版本为 `0.0.4`。

## V0.0.3

- “运行”页面把人工操作与对象改为可读中文，不再直接展示内部操作代码和完整对象 ID。
- 待确认人物的合并目标按“已确认人物、待确认人物”分组，已确认人物始终置顶。
- 支持把待确认人物直接并入已有已确认人物，并保留同框冲突拦截、幂等审计和安全撤销。
- 增加中文审计、已确认人物优先合并、冲突拒绝及撤销恢复测试。

## V0.0.2

- 人物名称改为可选；留空时按所选关系自动生成并顺延“关系 + 编号”，历史编号不复用。
- 待确认人物簇新增大尺寸最佳人脸、样本切换和对应原始录像的按需播放。
- 人物簇接口复用既有鉴权制品端点提供录像、发生时间和时长，不增加公开媒体地址。
- 增加空名称、历史编号、改名、簇录像映射及 HTTP Range 播放契约测试。

## V0.0.1

- 建立 NAS 单镜像、单容器、Python/Node 双进程架构。
- 实现只读录像摄取、稳定性检查、SHA-256 去重、租约恢复和 `5/20/60` 分钟重试。
- 接入固定 SHA-256 的 SCRFD 2.5G、ArcFace R50 与 ONNX Runtime CPU。
- 实现多人物轨迹、完整同帧共现证据、永久不可合并约束和未知人物自然聚类。
- 实现不预录人脸的人工命名、改名、人物/簇合并、簇拆分、误检和撤销。
- 永久保留高质量多样代表样本，使用有界检索索引控制 N100 匹配成本。
- 建立 SQLite 单写者、Alembic 迁移、持久化 Outbox、审计和可撤销服务端会话。
- 新增密码管理页面，覆盖事件、证据、人物、失败重试、下载状态、备份回执、存储和审计。
- 新增企业微信官方智能机器人 WebSocket 适配层；训练期身份/风险通知默认关闭。
- 新增 `xiaomi-lock-cloud-video V0.0.4` JSONL 下载状态桥接，不复用任何云端认证。
- 新增制品清单、SQLite 在线快照与 115 专项任务校验回执契约。
- 加固 Trusted Host、Argon2id、持久限速、CSRF、安全响应头、路径边界、只读根文件系统和日志脱敏。
- 固定 Python/Node/基础镜像依赖，补充公开树扫描、自动验证、部署与回滚文档。
- 增加冷白证据账簿管理端的响应式、键盘、减少动态、44px 触控与 AA 对比度保障。
- 兼容 Windows 短路径与规范路径指向同一批准目录的场景，同时拒绝符号链接和目录联接。
- 兼容 NAS 下载器生成的 `root:root 0640` 源录像：专用 UID 10001 只增加容器内读取组，宿主权限和只读挂载不变。
- 修复最小 capability 模式下持久数据目录首次交权后无法幂等重启的问题，不增加 `DAC_OVERRIDE`。
- 为容器内 Supervisor 增加仅用于优雅结束 UID 10001 子进程的 `KILL` capability，并要求重启日志无权限错误。
