# 自然学习与多人同框

## 不预录人脸

系统不要求家人、邻居或快递员专门站在门口录入。每条日常事件录像独立分析；清晰人脸先进入未知人物簇，用户在管理页面看到录像、场景图和最佳人脸后再命名。

```text
自然事件
  → 人脸质量门槛
  → 每人一条轨迹
  → 已知人物双阈值匹配，或进入未知簇
  → 人工命名/合并/拆分/误检
  → 高质量且有差异的代表样本永久积累
  → 后续事件继续校验，学习永不自动结束
```

训练阶段所有结果保存，但身份和风险通知默认关闭。系统不会为了触发通知而自动把未知人物命名为“陌生人”。

## 质量门槛

每张人脸综合检测分数、尺寸、清晰度、亮度和姿态质量。模糊、太小、过暗、过亮或无法提取特征的样本跳过，并在事件中保存固定原因。无清晰人脸时结果为“无法识别”，不是“陌生人”。

成为人物原型还需更高质量门槛，并与已有原型保持足够差异。合格代表样本永久保存且总数不封顶；重复样本不进入原型库。为降低实时匹配成本，人物检索只启用一组多样原型和综合质心，未启用样本仍永久留存、可审计且可用于未来重建。

## 身份判定

身份匹配同时要求：

- 最佳相似度达到接受阈值。
- 最佳与第二名之间达到最小差距。
- 模型版本一致。
- 候选人物没有同框不可合并冲突。

阈值是首版工作值，需要用真实门锁视角的人工标记逐步校准；公开数据集阈值不能直接当成家庭最终阈值。

## 多人同框

同一录像可以产生任意数量人物轨迹。系统保存每条轨迹出现过的全部采样帧索引；只裁剪计算用代表帧，不裁剪共现证据。

若两条轨迹曾在同一帧出现，永久写入 `cannot-link`：

- 自动未知簇不会把二者放在一起。
- 人工合并人物会被拒绝。
- 人工合并未知簇会被拒绝。
- 人工把待确认人物并入已确认人物也会被拒绝。

如果一个人因遮挡被拆成前后两个连续片段且从未同框，后续事件可以自动重新关联，也可以人工合并。若系统把不同人错放进一个未知簇，可逐个选择样本拆分；所有修正操作可撤销。

## 人物状态与人工标签

人物名称和关系由用户确定，可标为我、家人、朋友、邻居、快递员、保洁、访客、其他或已确认陌生人；名称留空时按关系自动顺延编号，历史编号不复用。“我”沿用家人的风险减分，“朋友”保持已知人物的中性风险语义，不自动忽略异常行为。人工确认后：

- 历史轨迹仍保留原始证据。
- 高质量样本晋升为永久代表样本。
- 新自然事件继续增加独立事件和日期观察。
- 人物可从 provisional 逐步变为 trusted，但学习不会停止。

“trusted”只表示样本和跨日证据更充分，不表示系统获得开锁权限，也不是安全保证。

## 通知策略

V0.0.3 初始状态：

- 身份识别通知：关闭。
- 风险事件通知：关闭。
- 下载、分析和企微运行故障通知：开启且页面不可关闭。

训练稳定后，用户可在管理页面开启身份或风险通知；启用前应先检查误识别、多人同框和不清晰样本统计。
