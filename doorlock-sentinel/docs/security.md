# 安全与隐私

## 账号与登录

- 公网页面只有密码，没有用户名。
- 密码以 Argon2id 保存，参数为 64 MiB 内存、3 次迭代、并行度 2。
- 首次密码由本地脚本随机生成，只写入 Git 忽略文件，不在终端回显。
- 会话令牌只存 SHA-256 摘要，Cookie 为 `Secure`、`HttpOnly`、`SameSite=Strict`。
- 会话最长 12 小时并绑定 User-Agent，可退出或撤销全部会话。
- 登录失败按客户端地址与 User-Agent 的加密摘要持久限速，默认 15 分钟窗口 5 次失败后锁定 30 分钟。
- 所有状态修改要求会话 CSRF 令牌，并校验请求 Origin。

## Web 边界

- 应用只绑定 NAS 回环端口，由共享入口网关终止公网 TLS。
- Trusted Host 只允许私有配置中的正式主机名和容器内主机名。
- 响应设置 CSP、HSTS、`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy` 和禁用敏感浏览器能力的 `Permissions-Policy`。
- API 与媒体证据响应为 `no-store`，页面不能被第三方 iframe 嵌入。
- 生产环境禁用 OpenAPI 和交互文档。

## 文件边界

- 录像目录只读挂载。
- 专用 UID 10001 仅加入容器内 `root` 补充组，以读取 NAS 下载器生成的 `root:root 0640` 录像；不改变宿主文件权限，也不授予写入、宿主 root 身份或额外 capability。
- 只接受批准根目录内的普通文件，拒绝符号链接、硬链接状态日志、路径穿越、越界文件和超大状态日志。
- 管理页面只按数据库登记的制品 ID 读取文件，不能提交任意本地路径。
- 容器根文件系统只读，`/tmp` 和 `/run` 使用有上限的 tmpfs。
- secrets 只读挂载到 `/run/secrets`，入口复制到临时运行目录并降权；不写入镜像层。

## 服务隔离

- Python 是 SQLite 唯一写者。
- Node bot 只能通过回环内部 API 和随机令牌操作 Outbox。
- 115 备份专项任务只使用独立内部令牌/私有挂载，不复用小米或 Home Assistant 凭据。
- 下载器状态日志只含固定错误码和不可逆报告摘要。
- 识别结果永远不触发开锁。

## 敏感数据

以下内容不得进入 Git、公开 Release、镜像、测试夹具、截图、日志或聊天：

- 门锁录像、缩略图、脸图、embedding 和真实数据库。
- 小米、米家、Home Assistant Cookie、令牌、账号或设备标识。
- 管理密码、密码哈希、pepper、内部 API 令牌和企业微信 Secret/UserID。
- 私有域名、NAS 真实路径、115 远端定位符和家庭真实时间线。
- InsightFace 模型权重。

公开测试只使用合成视频、模拟人脸后端、固定假时间和 `.invalid` 域名。

## 审计与通知

登录、退出、撤销会话、设置修改、人物命名/改名/合并、未知簇合并/拆分、误检、撤销和分析重试都有审计记录。日志格式化器不输出异常堆栈；企业微信消息只含固定操作字段和管理页面链接，不携带完整录像或人脸向量。

## 已知边界

- 密码直连公网的强度依赖高熵密码、TLS、限速和及时更新；没有第二因素。
- 企业微信与 115 的真实账号安全由各专项任务和其私有凭据管理承担。
- 人脸识别存在误识别和漏识别，只能作为人工复核提示，不能作为人身安全或犯罪判断。
